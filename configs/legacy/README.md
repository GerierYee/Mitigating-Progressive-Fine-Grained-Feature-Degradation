# Legacy experiment configurations

These files are retained to load historical experiment checkpoints and to
trace earlier ablations. They use the original implementation names
`SPD_Downsample`, `LightASFF`, `MHP_Block`, and `CAE_Module`.

For new runs, use `../models/cmd_yolo26n_pfgr.yaml`, whose canonical class
names match the terminology in the manuscript. Legacy comments are historical
notes rather than the public method definition.
